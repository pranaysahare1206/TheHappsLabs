About

MyHapps transforms your phone into a complete development sandbox. Create full-fledged utility apps using standard web technologies (HTML, CSS, JavaScript) directly on your device. Run them natively without an internet connection.

Discover apps created by others in the marketplace, backup your workspace to Google Drive, and access local storage, sensors, and camera directly from your code.

Common Issues

  • Code not running? — Ensure your main file is set correctly (e.g., index.html) by tapping the settings icon next to the file.
  • Limit reached? — Free users can only store 3 apps. Upgrade to premium or delete unused apps.
  • Permissions blocked? — If your HTML app needs camera/location, make sure to grant the permission when prompted by Android.
